# FSD 감속 버튼 보드

일반 ESP32 보드(ESP32-WROOM-32, 예: "ESP32 DEVKIT V1")를 S3XY 버튼("ENH_BTN")으로 동작시킨다.
폰은 블루투스 주소가 바뀌어 커맨더가 차를 다시 켤 때 못 찾는 것으로 보여(2026-11-11 실차, 추정), 주소가 고정인 보드를 커맨더 버튼으로 쓴다.
1단계 실차(2026-11-13): 차를 다시 켜도 커맨더가 보드에 저절로 붙고 신호도 됨.
2단계: 폰 앱(v0.15.0~, 설정 ⑥ "보드 경유")이 보드에 접속해 신호를 보내면 보드가 커맨더에 누른다.

## 프로그램 넣기 (PC, 크롬 또는 엣지)
보드를 **데이터 되는 USB A to C 케이블**로 PC에 연결하고 Espressif 공식 웹 도구 https://espressif.github.io/esptool-js/ 를 연다.
Baudrate **115200**(921600은 이 보드에서 실패) → [Connect] → 보드 포트(CP210x 등) 선택. 연결이 안 되면 BOOT를 누른 채 [Connect], 연결되면 뗀다.
포트가 안 보이면 PC에 USB 드라이버(보드의 USB 옆 칩: CP210x 또는 CH340)가 필요하다. **[Erase Flash]는 누르지 않는다**(페어링이 지워짐).

### 앱으로 무선 업데이트(앱 v0.16.0~, PC 필요 없음)
- **무선 업데이트 기능이 든 보드 프로그램(2026-11-14 이후 빌드)을 PC로 마지막 한 번 넣어야 한다** — 아래 "업데이트"대로 0x10000에 `cam-slowdown-board-app.bin`. 그 뒤로는 앱에서 한다.
- 앱 설정 ⑥ 보드 경유 칸에 "보드 프로그램: <보드 버전> (최신 <릴리스 버전>)"이 보인다. 감시를 끈 채 보드 전원을 켜고(차 USB) 폰을 가까이 두고 [보드 프로그램 업데이트].
- 앱이 릴리스의 `cam-slowdown-board-app.bin`을 받아 블루투스로 보낸다(1~3분, 파란 불이 아주 빠르게 깜빡). 보드가 md5로 확인하고 다시 켜지면 끝. 실패하면 보드는 원래 프로그램 그대로다.
- 커맨더·폰 페어링과 토큰은 그대로 남는다. 주행 중(감시 중)에는 업데이트할 수 없다.
- 무선 업데이트를 한 번이라도 한 보드를 다시 PC로 업데이트할 때는 0x10000의 `cam-slowdown-board-app.bin`과 함께 **0xe000에 `cam-slowdown-board-otadata.bin`** 도 넣는다(웹 도구에서 [Add File]로 두 줄). 안 넣으면 무선으로 넣었던 쪽 프로그램으로 계속 켜진다.

### 업데이트(이미 프로그램이 들어 있을 때 — 커맨더·폰 페어링 유지)
- 받기: https://github.com/jsbeth-code/yoonmind/releases/download/cam-slowdown-board-latest/cam-slowdown-board-app.bin
- Flash Address **0x10000**, 파일 `cam-slowdown-board-app.bin` → [Program]. 끝나면 EN 버튼을 한 번 누른다.

### 처음 넣을 때(빈 보드)
- 받기: https://github.com/jsbeth-code/yoonmind/releases/download/cam-slowdown-board-latest/cam-slowdown-board.bin
- Flash Address **0x0**, 파일 `cam-slowdown-board.bin` → [Program]. 끝나면 EN 버튼을 한 번 누른다.
- 이 파일은 페어링 저장 칸까지 덮을 수 있다 — 그러면 엔하우토에서 보드를 다시 추가한다.

파란 불이 2초마다 짧게 깜빡이면 정상(커맨더 기다리는 중).

## 커맨더에 등록
1. 차에서 FSD 감속 앱 설정 ⑥의 "S3XY 커맨더로 차 휠 조작"을 끄거나 "보드 경유"로 둔다(폰도 ENH_BTN이면 헷갈림).
2. 보드를 차 USB에 꽂는다(전원만 되면 됨 — 충전 전용 케이블도 됨).
3. 보드 BOOT를 **3초 넘게** 눌러 파란 불이 두 번씩 깜빡이게 한다(1분 동안 새 기기 페어링을 받음 — 그 밖엔 낯선 기기를 거절).
4. 1분 안에 엔하우토 앱 → Buttons → Add S3XY Button. 보드를 등록하고 클릭 = 크루징 속도 내림, 더블클릭 = 올림으로 지정.
5. 파란 불이 **계속 켜져 있으면** 커맨더 연결·준비 완료.
- 이미 등록된 커맨더는 다시 등록할 필요 없다(보드 프로그램을 업데이트해도 남음).

## 폰 앱과 연결(보드 경유, 한 번만)
1. 앱 설정 ⑥ "S3XY 커맨더로 차 휠 조작" 켬.
2. 보드 BOOT를 **3초 넘게** 누른다 → 파란 불이 두 번씩 깜빡(1분 동안 폰 페어링 받음).
3. 앱 설정 ⑥ [보드 페어링] → [찾기] → 폰에 페어링 요청이 뜨면 승인. "보드 페어링 됨"이면 끝(커맨더 연결이 "보드 경유"로 바뀜).
4. 감시를 켜면 앱이 보드에 접속한다. 설정 ⑥ 상태 줄과 카드의 커맨더 점이 초록이면 폰↔보드·보드↔커맨더 모두 정상.
- 보드는 페어링한 폰 하나만 받는다. 다른 폰으로 페어링하면 이전 폰은 못 쓴다.
- 암호화(페어링된 키)가 안 된 접속은 커맨더로 보지 않고 30초 뒤 끊는다.

## 보드 조작
| 조작 | 동작 |
|---|---|
| BOOT 짧게(1초 미만) | 클릭(감속 시험) |
| BOOT 1~3초 | 더블클릭(복귀 시험) |
| BOOT 3초 넘게 | 페어링 창 1분(새 커맨더·폰 등록) |
| BOOT 10초 넘게 | 저장된 페어링 모두 지우고 다시 시작(커맨더·폰) — 그 뒤 폰 블루투스 설정에서 ENH_BTN '기기 삭제' |

BOOT는 USB 옆 두 버튼 중 EN(RST)이 아닌 쪽(IO0·GPIO0·FLASH로 찍혀 있거나 글자 없음).

| 파란 불 | 뜻 |
|---|---|
| 계속 켜짐 | 커맨더 연결·준비 |
| 빠르게 깜빡 | 접속은 됐지만 준비 전 |
| 2초마다 짧게 | 커맨더 기다리는 중 |
| 두 번씩 깜빡 | 페어링 창(1분) |
| 아주 빠르게 깜빡 | 앱에서 무선 업데이트 받는 중 |

## 차가 켜지면 앱 감시 자동 시작(앱 v0.16.0~)
보드는 차가 깨어 있을 때만 전원이 들어온다. 앱 설정 ⑥ "보드가 켜지면 자동 시작(보드 경유)"(기본 켬)이면, 앱이 꺼져 있어도 폰이 보드 광고를 보고 감시를 켠다.
감시 중 보드 연결이 끊기고 60초 지나면 자동 정지("연결이 끊기고 60초 지나면 자동 정지" 설정을 따름). 감시를 직접 끄면 보드가 한 번 꺼졌다 켜질 때까지(약 3분 넘게 안 보였다가 다시 보일 때까지) 다시 켜지지 않는다.

## 기록 보기(필요할 때)
PC에 연결하고 https://espressif.github.io/esptool-js/ 의 Console 탭에서 115200으로 [Start]하면 동작 기록이 나온다.
