# 매매수첩

미국주식 매매 기록과 투자 근거, 정기 적립을 한 곳에서 관리하는 개인용 웹앱입니다.
별도 서버나 로그인 없이, 브라우저에서 열기만 하면 바로 사용할 수 있습니다.

**바로 사용하기:** https://jsbeth-code.github.io/yoonmind/

## 주요 기능

- **매매 기록**: 종목별 매수/매도 내역을 기록하고 FIFO 방식으로 보유분과 청산분을 구분
- **계좌 이동**: 실물로 다른 계좌에 이체한 주식을 매입 원가 그대로 이동 기록 — 매수/매도로 처리되지 않아 손익에 영향 없음
- **엑셀/PDF/이미지 가져오기**: 증권사에서 내려받은 거래내역 파일(xlsx/xls/csv), 토스증권 거래내역서 PDF(비밀번호 지원), HTS·MTS 화면 캡처 이미지에서 거래·시세·환율 정보를 자동 인식
- **포트폴리오 개요**: 계좌 통합 보기, 자산 분포 차트, 여러 개의 독립적인 분류 기준(그룹)으로 종목 나누어 보기
- **환율 관리**: 통화별 환율을 자동 조회하거나 수동/이미지 일괄 입력
- **백업/복원**: 전체 데이터를 JSON 파일로 내보내고 다시 불러오기

## 데이터 저장 방식

모든 데이터는 브라우저의 `localStorage`에만 저장되며, 외부 서버로 전송되지 않습니다.
다른 기기나 브라우저로 옮기려면 백업/복원 기능을 사용하세요.

## Anthropic API 키 (선택)

이미지에서 거래·시세·환율을 자동으로 읽어오는 기능은 Anthropic API를 사용합니다.
이 기능을 쓰려면 본인의 Anthropic API 키를 앱 내에서 입력해야 하며, 키는 브라우저의
`localStorage`에만 저장되고 Anthropic API로 직접 요청을 보내는 데만 쓰입니다. 공용 컴퓨터에서는
사용을 피하고, 다른 사람과 이 파일을 공유할 때는 먼저 키를 지워주세요. API 키 없이도
수동 입력 기능은 모두 사용할 수 있습니다.
