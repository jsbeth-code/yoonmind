# 유료 데이터 수집 가이드 (Chrome → 여기 붙여넣기용)

Claude Code(이 프로젝트)는 무료 웹 검색만 가능하고, 사용자가 로그인한 유료 사이트(시킹알파·코이핀·모틀리풀)에는 접근할 수 없다.
**Chrome의 Claude(또는 직접 복사)로 아래 항목을 긁어와 채팅에 붙여넣으면**, 이 프로젝트의 6단계 분석 + 대가 스코어카드 + PDF 보고서에 그대로 반영한다.

## Chrome의 Claude에게 줄 지시문 (복사해서 사용)

```
아래 종목의 시킹알파(또는 코이핀) 페이지를 열어서 다음 데이터를 표로 정리해줘. 
숫자는 정확히, 기준일(as of 날짜)도 같이. 없으면 "N/A"로.
종목: [티커/기업명]

1. 밸류에이션: 현재가, 시가총액, 후행 PER, 선행 PER(FY1·FY2), PEG, EV/EBITDA, PSR, PBR, 배당수익률
2. 시킹알파 Quant Rating(점수/등급) + Factor Grades 5개: Valuation / Growth / Profitability / Momentum / EPS Revisions
3. 애널리스트 컨센서스: Wall Street 등급 분포(매수/보유/매도 수), 평균·최고·최저 목표주가, SA Authors 등급
4. 실적 추정: 향후 2년 매출·EPS 컨센서스 추정치와 성장률(YoY)
5. 수익성/재무: 매출총이익률·영업이익률·순이익률, ROE, ROIC, FCF(잉여현금흐름), 순현금/순부채, 부채비율
6. 최근 EPS 리비전 동향(상향/하향), 최근 어닝 서프라이즈 여부
7. (있으면) SA 애널리스트 아티클의 강세/약세 핵심 논거 3줄 요약
```

## 이 데이터가 내 분석 어디에 쓰이나 (프레임워크 매핑)

| 유료 데이터 | 반영되는 분석 파트 | 왜 중요한가 |
|---|---|---|
| 정확한 선행 PER·PEG·EV/EBITDA·PSR | 3.기업분석 / 스코어카드 **A-3(밸류·안전마진)**, **B-2(성장의 질)** | 무료 소스는 값이 들쭉날쭉. **A-3가 등급을 가르는 종목(GE·KLA·삼성전기)**은 정밀 밸류가 결정적 |
| SA Factor Grades (Valuation/Growth/Profitability/Momentum/EPS Rev.) | 스코어카드 전반 교차검증 | 대가 기준(A-3·A-6·A-7)과 직접 대응 — 내 판정과 대조 |
| 컨센서스 목표주가·등급 분포 | 3.기업분석(애널리스트 견해 비판) | 시장 컨센서스와 내 의견 괴리를 정량화 |
| FY1·FY2 매출·EPS 추정 | 4.재무분석 / A-6·B-2 | 선행 멀티플·성장률 계산의 정확도↑ |
| ROE·ROIC·FCF·부채비율 | 4.재무분석 / **A-4·A-7** | 재무건전성·효율성 판정의 정밀도↑ (한성기업식 부채 리스크 포착) |
| EPS 리비전·어닝 서프라이즈 | 2.뉴스분석 / A-6 | 이익 모멘텀·추정 신뢰도 |

## 활용 원칙

- 유료 데이터를 붙여주면, **내 무료 분석과 교차검증**하고 **유료 매체가 놓쳤거나 과장한 부분을 비판적으로 비교**한다(스킬 규칙).
- 유료 데이터가 반영된 보고서는 "기술적 지표 소스 기준일 불일치" 같은 고지를 줄이고, 밸류에이션 판정을 더 단단히 한다.
- 최소한 **밸류에이션(1번)만이라도** 붙여주면 A-3 판정 정밀도가 크게 오른다. 전부 없어도 되고, 있는 것만 줘도 반영한다.
