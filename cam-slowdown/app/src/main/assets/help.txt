# FSD 감속 — 처음 설치 도움말

이 앱은 테슬라 FSD로 달릴 때 과속카메라 앞에서 속도 프로필을 자동으로 낮췄다가, 지나가면 다시 올려 줍니다. 차의 오른쪽 휠을 대신 눌러 주는 장치(S3XY 커맨더)를 폰이 버튼처럼 조종하는 방식입니다.
개인적으로 나눠 쓰는 앱입니다. 운전 책임은 운전자에게 있고, FSD는 늘 지켜보면서 쓰세요.
주행 중에는 폰을 만지지 마세요. 화면 조작은 정차 중에만 하고, 주행 중 문제가 생기면 휠로 직접 프로필을 올리세요.

## 0. 준비물
- 안드로이드 폰 (안드로이드 8 이상). 아이폰은 안 됩니다.
- 테슬라 FSD가 되는 차.
- 차에 설치된 enhauto S3XY 커맨더(Gen2)와 폰의 enhauto 앱. 커맨더가 없으면 "음성 안내만" 쓸 수 있습니다(7번 참고).
- 처음 설정은 집이나 주차장에서, 차에 시동(전원)이 켜진 상태로 하세요. 30분쯤 걸립니다.

## 1. 앱 설치
1. 폰 브라우저에서 아래 주소를 열어 cam-slowdown.apk 를 받습니다.
   https://github.com/jsbeth-code/yoonmind/releases/download/cam-slowdown-latest/cam-slowdown.apk
2. 받은 파일을 누릅니다. "출처를 알 수 없는 앱" 경고가 나오면 [설정] → 이 브라우저(크롬 등)에 "허용"을 켜고 돌아와서 [설치].
3. "Play 프로텍트" 경고가 나오면 [무시하고 설치] (개인 배포 앱이라 나옵니다).
4. 설치가 끝나면 브라우저의 "출처를 알 수 없는 앱" 허용은 다시 꺼 두세요(안전을 위해).
5. 다음부터는 앱이 새 버전을 알려 줍니다. 설정 ⑩ [업데이트 확인]으로도 받을 수 있습니다. 새 버전은 그냥 덮어 설치하면 됩니다(앱을 지우지 마세요 — 지우면 커맨더 연결을 다시 해야 합니다).

## 2. 권한 허용
앱을 처음 열면 권한을 물어봅니다. 전부 [허용]을 누르세요.
- 위치: "정확한 위치"를 꼭 켠 채로(대략적 위치만 허용하면 동작하지 않습니다) [앱 사용 중에만 허용]을 고른 뒤, 설정 ⑥ 아래 [위치 '항상 허용' 요청]을 눌러 "항상 허용"으로 바꿉니다. 그래야 화면을 꺼도 카메라를 봅니다.
- 근처 기기(블루투스): 커맨더와 연결하는 데 필요합니다.
- 알림: 감시 중 상태 표시에 필요합니다.
- 설정 ⑥의 [배터리 최적화 제외 요청]도 눌러 "허용"하세요. 안 하면 폰이 앱을 꺼 버릴 수 있습니다.
- 설정 ⑦의 ['다른 앱 위에 표시' 권한 요청]을 눌러 이 앱을 켭니다. 다른 앱을 볼 때 작은 알약 창으로 거리·속도를 보여 줍니다. 필요 없으면 설정 ⑦ "다른 앱 위에 알약 창"을 끄세요(그러면 점검의 권한 경고도 사라집니다).
- 설정(⚙)은 메인 화면 아래 판을 위로 끌어 올리면 나오는 [⚙ 설정]에 있습니다. 앱 기록도 같은 곳(아래 판을 올린 화면의 "기록")에서 봅니다.

## 3. 카메라 데이터 넣기 (필수, 한 번만)
앱은 경찰청 단속카메라 목록을 예비 자료로 씁니다. (평소엔 카카오내비 정보를 쓰고, 카카오가 끊길 때 이 목록으로 판단합니다.)
1. 폰 브라우저에서 공공데이터포털(data.go.kr)을 열고 "전국무인교통단속카메라표준데이터"를 검색합니다.
2. 검색 결과의 [파일데이터] 중 "전국무인교통단속카메라표준데이터"를 열고 [다운로드](CSV)를 눌러 폰에 받습니다. (로그인 없이 됩니다. 카톡 등으로 옮기면 한글이 깨질 수 있으니 폰에서 직접 받으세요.)
3. 앱 메인 화면 아래 판을 위로 끌어 올려 [데이터·테스트 도구 ⋮] → [카메라 데이터 (경찰청 전국 CSV)] → 받은 파일을 고릅니다.
4. 점검에 "카메라 OO,OOO개"가 나오면 끝.

## 4. 도로망 데이터 넣기 (강력 권장, 한 번만)
옆 도로·반대편 차선 카메라에 잘못 반응하는 것을 크게 줄여 줍니다.
1. 폰 브라우저에서 아래 주소를 엽니다. 페이지 아래쪽 Assets 목록에서 kr-roads.zip 을 눌러 받습니다(수십 MB, 와이파이 권장).
   https://github.com/jsbeth-code/yoonmind/releases/tag/cam-slowdown-roads
2. [데이터·테스트 도구 ⋮] → [도로망 데이터 (OSM kr-roads.zip)] → 받은 파일을 고릅니다.
3. 점검에 "도로망 … 길 N개"가 나오면 끝.

## 5. 내 차 프로필 정하기
설정(⚙)의 ①②에서 정합니다.
- ① 평소 프로필: 평소 FSD를 어떤 속도 프로필로 쓰는지(예: Mad Max).
- ② 카메라 앞 프로필: 카메라 앞에서 어디까지 내릴지(예: 스탠다드, 컴포트).
- 프로필은 아래에서 위로 나무늘보 → 컴포트 → 스탠다드 → 신속주행 → Mad Max 순서입니다. 앱은 두 프로필의 칸 차이만큼 휠을 아래로 눌렀다가, 지나가면 그만큼 위로 올립니다.
- 내 차 화면의 프로필 순서·개수가 다르면(소프트웨어 버전에 따라 다를 수 있음) 이름보다 "칸 차이"가 중요합니다. 예를 들어 차에 3단계만 있고 맨 위에서 맨 아래로 2칸 내리고 싶으면, 앱에서 ① Mad Max, ② 스탠다드(2칸 차이)를 고르면 됩니다. 반드시 6번의 테스트로 실제 몇 칸 움직이는지 확인하세요.

## 6. S3XY 커맨더 연결 (차를 직접 조종하려면)
처음 한 번만 합니다. 차 안에서, 시동이 켜진 상태로 하세요.
1. 앱 설정 ⑥ "차와 연결"에서 [S3XY 커맨더로 차 휠 조작]을 켭니다.
2. 같은 자리의 [페어링하기]를 누릅니다. (폰 블루투스 이름이 잠시 ENH_BTN으로 바뀝니다.)
3. 폰에서 enhauto 앱을 열고 Buttons → [Add S3XY Button]을 누릅니다.
4. 폰에 "블루투스 페어링 요청"이 뜨면 [페어링]/[승인]을 누릅니다.
5. 설정 ⑥에 "✔ 커맨더 연결됨 · 버튼 준비"가 보이면 연결 성공입니다. (메인 화면 아래 판의 기록에는 "핸드셰이크 응답 — 커맨더가 버튼으로 인식", "알림 구독됨 — 버튼 준비"가 남습니다.)
   연결되면 [페어링하기]를 한 번 더 눌러 페어링 모드를 끕니다(폰 블루투스 이름이 원래대로 돌아옵니다).
6. enhauto 앱에서 새로 생긴 버튼의 기능을 지정합니다.
   - 클릭(한 번 누름) = 크루징 속도 내림 (FSD에서는 오른쪽 휠 아래 = 프로필 한 칸 내림)
   - 더블클릭(두 번 누름) = 크루징 속도 올림 (프로필 한 칸 올림)
7. 확인 테스트 (주차 상태, 차 화면에서 FSD 프로필이 보이게 하고):
   - 설정 ⑥ [감속 신호 테스트] → 차의 프로필이 ①에서 ②까지 정확히 몇 칸 내려가는지 셉니다.
   - [복귀 신호 테스트] → 정확히 ①로 돌아오는지 봅니다.
   - 칸 수가 안 맞으면 클릭이 빠진 것입니다. 설정 맨 아래 고급 설정의 "누름 사이 간격"을 늘려 보세요.
   - 테스트는 감시를 끈 상태에서만 됩니다.

다음부터는 차에 타면 커맨더가 알아서 붙습니다. 메인 화면 점검에 "✔ 커맨더 연결됨 · 준비", 아래 줄에 초록 "● 커맨더"가 보이면 정상입니다.

## 7. 커맨더 없이 음성만 쓰기
설정 ⑥ [S3XY 커맨더로 차 휠 조작]을 끄면, 카메라 앞에서 "감속합니다"만 말해 주고 휠은 직접 돌립니다. 차에 아무것도 달지 않는 가장 안전한 방법입니다.

## 8. 소리 설정
설정 ⑦에서 [안내 소리 테스트]로 들어 봅니다.
- 기본은 "폰 스피커(알람 채널)" — 진동 모드여도 폰에서 납니다. 폰 알람 볼륨을 적당히 올려 두세요.
- 차 스피커로 듣고 싶으면 "차 스피커 (통화 채널, 실험)"를 고릅니다(안내할 때 잠깐 통화처럼 연결됨).
- "미디어 채널"은 차 오디오 소스가 블루투스(폰)일 때만 차에서 들립니다. 보통은 고르지 마세요.
- 길 안내·카메라·과속·구간단속·어린이보호구역 안내는 카카오내비 음성이고, 이 앱은 "감속합니다"·"복귀합니다"와 장치 경고(GPS·커맨더·카카오 끊김)만 말합니다.

## 9. 차에 타면 자동으로 켜기
1. 설정 ⑥ [차 블루투스에 연결되면 자동 시작]을 켜고, 아래 목록에서 내 차(예: "Tesla Model Y …")를 고릅니다.
2. 2번의 "위치 항상 허용"과 "배터리 최적화 제외"가 되어 있어야 화면을 안 켜도 시작됩니다.
3. 설정 ⑥에 "✔ 자동 시작 조건 모두 충족", 메인 점검에 "✔ 자동 시작: (차 이름) 연결 시"가 보이면 됩니다.
4. 차에서 내려 블루투스가 끊기면 60초 뒤 자동으로 꺼집니다(설정 ⑥ "연결이 끊기고 60초 지나면 자동 정지"가 켜져 있을 때, 기본은 켜짐).
5. 처음엔 메인 화면의 [▶ 감시 켜기](또는 아래 줄 [▶ 켜기])로 직접 켜 보세요. 지도가 카카오내비 화면으로 바뀌고 아래 줄에 초록 점 두 개가 보이면 정상입니다.

## 10. 테슬라 목적지 따라가기 (선택)
테슬라 내비에 목적지를 찍으면, 앱이 카카오 경로를 그 목적지로 맞춰 경로 위 카메라만 봅니다. 없어도 카메라 감속은 됩니다.
1. 설정 ⑨ [목적지 따라가기]를 켭니다.
2. [테슬라 연결] → 테슬라 계정으로 로그인 → 권한 허용(차량 정보·위치).
3. "연결 완료" 화면에서 [앱으로 돌아가기]를 누릅니다. 안 돌아오면 화면에 보이는 세션 키를 복사해 설정 ⑨ 칸에 붙여 넣고 [세션 키 저장].
4. 그 다음부터 목적지를 찍으면 앱에 경로 고르기 화면(추천 · 시간 우선 · 무료도로 · 최단거리)이 뜹니다. 15초 안에 고르거나, 그냥 두면 기본 경로로 갑니다(정차 중에만 누르세요).
- 앱은 차를 깨우지 않고, 차가 깨어 있을 때만 목적지를 읽습니다. 테슬라 비밀번호는 앱에 저장되지 않습니다.
- 알아 둘 점: 로그인하면 테슬라 접속 권한(토큰)이 앱을 준 사람이 운영하는 중계 서버에 보관되고, 목적지를 확인할 때마다 그 사람 계정으로 테슬라 유료 API가 호출됩니다. 원치 않으면 이 기능은 쓰지 않아도 됩니다. 설정 ⑨ [연결 끊기]를 누르면 서버에서도 지워집니다.

## 11. 주행 중 화면 보는 법
- 지도는 카카오내비 화면 그대로입니다(속도에 따라 확대·축소, 교차로 그림, 차로 안내).
- 아래 한 줄: 목적지 · ● 카카오 ● 커맨더 · 도착 시각 · [끄기]. 점이 초록이면 정상입니다.
- 카메라가 가까워지면 왼쪽에 주황 알림이 떠서 반짝입니다: 제한속도 · 남은 거리 · "▼ 스탠다드로 내리는 중".
- 아래 판을 위로 끌어 올리면 프로필 바꾸기, [지금 복귀], 점검, 기록, 도구가 나옵니다(정차 중에만 조작하세요).

## 12. 잘 안 될 때 (자주 있는 경우)

[커맨더]
- "커맨더 없음"(빨간 점) / "커맨더가 연결되지 않았습니다" 음성
  → 폰에 블루투스 페어링 요청 창이 떠 있으면 [승인]. 앱이 알아서 다시 붙이려고 요청합니다.
  → 그래도 안 되면(차를 세운 뒤): enhauto 앱에서 이 버튼을 지우고, 6번을 처음부터([페어링하기] → Add S3XY Button → 승인 → 버튼 기능 지정) 다시 합니다. 앱을 지웠다 깔았거나 업데이트 직후에 가끔 필요합니다.
  → "커맨더 다시 페어링이 필요합니다" 음성이 나오면 바로 위 방법대로 하세요.
- 커맨더가 붙었는데 차 프로필이 안 바뀜
  → enhauto 앱에서 버튼 기능(클릭 = 크루징 속도 내림, 더블클릭 = 올림)이 지정됐는지 확인. 버튼을 새로 추가하면 기능 지정이 빠집니다.
  → FSD가 켜져 있지 않으면 휠 기능이 프로필이 아니라 다른 것일 수 있습니다. 주차 중 테스트는 차 화면에서 FSD 프로필이 보이는 상태로 하세요.
- 프로필이 정한 것보다 덜/더 움직임
  → 클릭이 빠지는 것입니다. 설정 맨 아래 고급 설정 "누름 사이 간격(ms)"을 1000 → 1500으로 늘리고 6번 테스트를 다시.
  → 평소가 Mad Max면 복귀 때 한 번 더 누르는 게 정상입니다(맨 위에서는 더 눌러도 그대로라 안전). 단, 내 차의 맨 위 프로필이 앱의 Mad Max 자리와 다르면 6번 테스트로 꼭 확인하세요.

[자동 시작·감시]
- 차에 타도 자동으로 안 켜짐
  → 설정 ⑥에서 고른 차가 맞는지(테슬라는 "오디오" 블루투스 이름), 점검에 "자동 시작 조건 모두 충족"이 보이는지 확인.
  → "차 연결됨 — FSD 감속 / 탭해서 시작" 알림만 뜨면 2번의 위치 "항상 허용"·배터리 최적화 제외가 빠진 것입니다(알림을 누르면 바로 시작).
- 주행 중 감시가 꺼짐
  → 최근 앱 목록에서 이 앱을 밀어 닫으면 감시가 꺼집니다(차 연결 자동 시작은 유지). 닫지 말고 홈 버튼으로 나가세요.
  → 삼성폰은 설정 → 배터리 → 백그라운드 사용 제한에서 이 앱을 "제한 없음"으로 두세요.
- "GPS 신호 없음"
  → 지하주차장·터널에서는 정상입니다. 계속되면 폰 위치(GPS)가 켜져 있는지, 앱 위치 권한이 "항상 허용"인지 확인.

[카카오·소리]
- "카카오 끊김"(노란 점): 터널·통신 불량 때 잠깐 생기고 저절로 돌아옵니다. 그동안은 경찰청 목록으로 판단합니다.
- "카카오 연결 실패 C103": 앱 쪽 등록 문제입니다. 기록을 캡처해 앱을 준 사람에게 바로 알려 주세요. (그동안도 경찰청 목록으로 감속은 됩니다.)
- "카카오 연결 실패"(다른 번호): 인터넷 연결을 확인하고 감시를 껐다 켜세요.
- 안내 소리가 안 남
  → 폰 알람 볼륨(소리 설정의 "알람")을 올리세요. 진동 모드여도 알람 채널은 납니다.
  → 설정 ⑦ [안내 소리 테스트]. 그 아래 음성 엔진 상태에 문제가 보이면 폰 설정 → 텍스트 음성 변환(TTS)에서 한국어 음성을 받으세요.
- 길 안내 목소리만 안 남: 기록에 "카카오 음성 직접 재생 실패"가 있으면 캡처해 주세요.

[카메라 판단]
- 반대편·옆 도로 카메라에 감속함 → 4번 도로망을 넣었는지 확인. 잘못 내려가면 휠로 올리거나, 정차 중 [지금 복귀].
- 카메라 앞인데 안 내려감 → 점검에 "카메라 데이터 없음"이 있으면 3번. 설정 ⑤에서 꺼 둔 종류(신호 카메라·이동식)인지 확인.
- 내려간 채로 안 올라옴 → 주행 중엔 휠로 직접 올리세요. 정차 중이면 아래 판을 열고 [지금 복귀]. 감시를 끄면 자동으로 올리지 않습니다(안전 쪽).

[설치·업데이트·테슬라]
- 업데이트 설치가 "앱이 설치되지 않음"으로 실패: 다른 경로로 받은 옛 버전과 서명이 달라서입니다. 앱을 지우고 새로 설치하세요(이 경우 3·4·6번을 다시 해야 합니다).
- 테슬라 로그인 뒤 앱으로 안 돌아옴: 브라우저에 보이는 세션 키를 길게 눌러 복사 → 설정 ⑨ 칸에 붙여 넣고 [세션 키 저장].
- 목적지를 찍었는데 반응 없음: 차가 잠들어 있으면 못 읽습니다. 출발해서 움직이면 2분 안에 읽고, 아래 판의 [↻ 목적지 확인]으로 바로 확인할 수도 있습니다.

그 밖의 문제는 아래 판 → 기록을 캡처해서 앱을 준 사람에게 보내 주세요.
